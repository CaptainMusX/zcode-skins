# ZCode skins 1.1.0 功能对照与验收

对照本机 Hermes skins 1.3.5，目标宿主为 ZCode Desktop 3.14.4。

| 能力 | 状态 | ZCode 实现 |
| --- | --- | --- |
| 六款内置皮肤、筛选画廊 | 已有 | 保留素材、标签与现有选择 |
| 试穿、应用、恢复 | 已有并修复 | 保留持久化皮肤，退出清除自身配色 |
| 自定义配色与 JSON 导入导出 | 已有 | 保留工坊与配色对比度处理 |
| 深浅色自适应 | 修复 | 原生 theme-…-light/dark 优先于系统外观 |
| 消息气泡底色 | 补齐 | 单独使用 bubbleOpacity；0 隐藏底色，100 保留原生底色，文字与边框不降透明度 |
| 输入框、摘要胶囊透光 | 修复 | 底色随界面透光度；输入框和胶囊磨砂分别跟随现有滑块 |
| 菜单、子菜单、弹出卡片 | 修复 | 保留原生圆角与状态，定位容器透明，菜单内容只着色一次 |
| Wallpaper Engine 库、搜索、类型筛选 | 已有 | 保留 ZCode 目录索引、授权选择与缩略图修复 |
| 图片、视频、Scene、Web | 已有并补齐 | 保留本地文件桥和 IndexedDB，升级场景解析器 |
| cover / contain / fill、实时 / 静帧 | 已有 | 保留播放选项与持久化 |
| 声音、音量、隐藏暂停 | 已有 | 保留视频与场景音量、暂停协议 |
| 蝴蝶 X-ray、靠近光标隐藏与恢复 | 补齐 | 主窗口坐标按实际播放器矩形映射，逐帧合并最新位置 |
| shake、普通水面反射 | 补齐 / 保留 | 使用 1.3.5 已验证的解析和着色器；不重新加入光标波纹模拟 |
| 网页光标事件 | 补齐 | 沙箱内转发 mousemove / mouseleave |
| 场景调度、纹理与粒子预算 | 补齐 | 单调度器、目标上限 30 FPS；按 Hermes 预算控制资源 |
| 上下文故障、切换与销毁 | 补齐 | 最多一次重建，重复故障静帧回退；取消加载并释放资源 |
| 旧场景缓存迁移 | 补齐 | parserVersion 6；新缓存成功后替换，源包不可用保留旧预览 |
| 设置入口、快捷键 | 已有 | ZCode 外观下的皮肤中心，以及 Ctrl+Shift+S / Alt+S |
| Hermes 原生插件注册与 REST 网关 | 宿主不适用 | ZCode 使用永久渲染注入与本地文件桥 |
| Hermes 终端透明补丁与专有 HUD | 宿主不适用 | 不将 Hermes 的终端配置与 DOM 选择器套到 ZCode |

## 验证记录

- Node 回归测试包含播放器调度、光标转发、旧缓存、资源取消、真实 ZCode ASAR 安装 / 重复安装 / 还原及过期备份拒绝。
- Edge Chromium 使用安装版的原生 CSS 验证深浅色与透光、磨砂端点；计算样式和截图保存于 `verification/`。
- SwiftShader 真实 GLSL 像素验证覆盖 cover / contain / fill：光标处蓝色替换纹理，离开后红色原纹理，暂停后无新增绘制。软件渲染结果不能代替硬件 GPU 长时间压力验收。
- 本机 2805854912 蝴蝶 PKG 提取出 X-ray 图层与两项资源，缺失数为 0，Steam 原文件 SHA-256 未变；2872509253 的 Eye_Back / Eye_Front shake 提取通过。
- 当前安装、官方归档和 localStorage 在更新前备份于 `verification/before-1.1.0-20261004-194527/`。安装脚本另外保留每次更新前的归档，部署时验证宿主版本、未修改条目与注入内容 SHA-256。
