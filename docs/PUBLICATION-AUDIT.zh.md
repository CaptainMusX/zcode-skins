- 远端原有 3 个提交树未包含个人截图、聊天记录、账号配置、`.env`、认证文件、场景缓存或 Python 字节码。

- 原有提交作者/提交者使用个人邮箱，经仓库所有者授权改为 GitHub noreply，并重写公开分支历史。未来本仓库提交使用同一 noreply 身份。

- 已经被下载或缓存的旧历史无法由一次 Git 重写保证清除；GitHub 对历史清理的范围说明见 [官方文档](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。
