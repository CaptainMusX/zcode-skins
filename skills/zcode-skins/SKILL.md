# ZCode 皮肤中心 (ZCode Skins)

本插件为 ZCode Desktop 提供专属的主题美化与视觉增强能力。

## 主要功能
1. **主题画廊**：内置多款高精主题立绘与调色方案，支持暗色与浅色自适应切换；
2. **自定义壁纸**：支持本地图片（JPG/PNG）、本地视频（MP4/WebM）或 Web 动态壁纸；
3. **玻璃拟态与毛玻璃**：支持深度调节侧边栏、对话流、输入框的毛玻璃模糊度（Blur）与半透明透光度（Translucency）；
4. **Steam Wallpaper Engine 联动**：自动检索本地 Steam 订阅的动态壁纸并即时播放；
5. **快捷键**：在 ZCode 任意界面按下 `Ctrl + Shift + S` 或点击右下角 🎨 调色盘胶囊即可呼出配置面板。

## 使用指引
- 向 ZCode 提问：“打开皮肤中心” 或 “更换壁纸”；
- 运行配套启动器一键开启美化体验。
